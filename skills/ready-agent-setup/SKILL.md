# Agent setup

Read `../../policies/agent-setup.md` and `../../policies/writing.md` completely.
Resolve these paths relative to this skill directory.
Read the repository's instructions and applicable task-specific skills.

Use the operator's own authentication, authority, and native permission controls.
Do not transfer credentials or full history between products.

If `agent-workflow` is installed, use its existing controller for assigned PR tasks.
Do not start another watcher or promise monitoring without a running mechanism.
Approval does not end review ownership. Rereview new heads until actual merge or close.

This skill provides instructions, not an OS sandbox or a universal permission adapter.
